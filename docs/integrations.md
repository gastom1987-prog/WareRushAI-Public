# WareRushAI integrations

This document summarizes the integration categories and services listed on the WareRushAI integrations page:

https://warerushai.com/integrations

The website is the source of truth for current availability, geographic coverage, and service-specific behavior. Capabilities are not necessarily identical across all integrations.

## Marketplace compliance workflow

The integrations page describes WareRushAI as helping merchants prepare listings for different marketplace requirements. Marketplace requirements may include category selection, mandatory attributes, barcode, manufacturer and product-safety information, product condition, and shipping settings.

The described workflow includes:

- Preparing channel-specific required fields from available product data and photos.
- Checking product information against marketplace requirements before upload.
- Explaining missing merchant-provided information in plain language.
- Using marketplace rejection feedback to improve product data preparation.

AI assists with data preparation and suggestions. Merchant review remains important, especially for information that must be verified from the physical product.

## Custom integrations

The website invites merchants to request an integration for an ERP, local carrier, custom webshop, or another system that has an official API. The site says the team will review the system documentation and requirements. It also states that a connection useful to other merchants may be added to the offering without a fee.

The described process is:

1. Share the system name and the needed data or workflows (products, stock, orders, invoices, or shipping).
2. Review the official API documentation and perform a security check.
3. Test the first write using a single item before enabling broader use.
4. Operate the connection and provide support after activation.

Custom integration requests: api@warerushai.com
